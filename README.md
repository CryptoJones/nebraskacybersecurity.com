# Nebraska Cybersecurity

> **nebraskacybersecurity.com** — a community directory of Nebraska's cyber organizations.

One state, one mission: defending Nebraska's networks, systems and data — from Omaha to the panhandle. The site highlights the organisations doing that work, and how you can plug in.

## Sections

| Anchor | Contents |
|---|---|
| `#state` | State government & defense — OCIO / JSOC, Cybersecurity Planning Committee & Statewide Plan, Nebraska National Guard, NIAC, NITC |
| `#community` | Professional community & training — Cyber Strong Nebraska & Cyber Tatanka, NEbraskaCERT CSF, DC402 & Kernelcon, ISC2 / ISACA / InfraGard / OWASP chapters, industry partners |
| `#education` | Education & workforce — UNO NebraskaCYBER (NSA CAE-CD + CAE-CO) & Nullify, UNL, Bellevue University, MCC / NECC / SCC, Offutt AFB / USSTRATCOM |
| `#events` | The recurring Nebraska cyber calendar (monthly CSF, DC402, chapters; annual Cyber Tatanka, Cyber Security Conference; Kernelcon) |
| `#get-involved` | How to attend, train, join, study, and submit an organisation |

## Run locally

No build step — it's a static site (HTML + one CSS file).

```bash
python3 -m http.server 8000        # or: npx serve .
open http://localhost:8000
```

## Sources

Content was researched from primary sources (Nov 2026): Nebraska Statewide Cybersecurity Plan (2023, slcg.nebraska.gov), GovTech profiles of the OCIO JSOC (2025–2026), Cyber Strong Nebraska / Cyber Tatanka releases (UNL, DVIDS, Army.mil, Nebraska National Guard, 2025–2026), NEbraskaCERT, DC402, ISC2 Omaha–Lincoln, ISACA Omaha, UNO NebraskaCYBER, and university/community-college program pages. Stats: ~1,500 public-sector organizations in the statewide plan's scope; OCIO cyber staff grown ~4× since mid-2025; Cyber Tatanka trained 750 professionals (2022–2026). This is a community directory, **not an official government site** — confirm details with each organization.
